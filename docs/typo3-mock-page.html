🔧 Debug-Hinweise (DevTools öffnen mit F12)

Wenn der iframe leer/grau bleibt, prüfe in der Console:

  • CSP-Block: Refused to frame ... because an ancestor violates ... frame-ancestors → der Host dieser Mock-Page muss in APP_FRAME_ANCESTORS der App ergänzt werden.
  • CORS / Origin-Block: API-Calls scheitern mit 403 error.unauthorizedOrigin → Host in CORS_ALLOWED_ORIGINS ergänzen.
  • Mixed Content: Mixed Content: The page at 'http://...' was loaded over HTTP, but requested HTTPS → diese Mock-Page muss über HTTPS geladen werden.
  • Sandbox blockiert localStorage: User-Settings (Sprache) werden nicht gespeichert → allow-same-origin im Sandbox-Attribut prüfen.
